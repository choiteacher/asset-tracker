# 자산 트래커

내년 아파트 분양에 대비해 개인 자산 흐름을 추적하는 웹앱입니다. 정기예금·적금·청약저축·주식·펀드·현금과 대출을 등록하면 현재 순자산을 초 단위(0.1원)로 보여주고, 분양 지급일마다 자금이 충분한지 예측합니다.

> **투자 자문이 아닌 참고용 추정치이며 실제 금액과 다를 수 있습니다.**

- 배포 주소: https://choiteacher.github.io/asset-tracker/
- 로그인은 **관리자 계정 1개**(Firebase Authentication, 회원가입 없음), 데이터는 **Cloud Firestore**에 저장합니다.
- Firestore에는 브라우저에서 **잠금 해제 비밀번호로 암호화한 암호문만** 올라갑니다. 서버(Firebase)에서도 내용을 볼 수 없습니다.
- 입력할 때마다 자동 저장되고, PC·휴대폰 어디서든 같은 데이터를 봅니다. 브라우저에는 사본을 남기지 않습니다.
- 처음 설정: [docs/FIREBASE_SETUP.md](docs/FIREBASE_SETUP.md)

## 주요 기능

| 화면 | 내용 |
|---|---|
| 대시보드(보기) | 순자산 실시간 표시(세후/세전), 유동·동결·부채, 이자 증가 속도, 세금 현황, 상품별 현황, 상환 현황, 금융 Tip, 다가오는 일정(D-day) |
| 분양 D-day(보기) | 분양 예정일까지 남은 일수, 지급일별 필요 자금 vs 예상 유동자산, 월별 예상 추이 그래프, "만약에" 계산 |
| 자산 기록(보기) | 하루 1회 스냅샷, 주별·월별 순자산 그래프, 유동/동결 구성 변화, 변경 내역 타임라인 |
| 대출 상세(보기) | 상환 스케줄 표, 잔액 추이 그래프, 추가 상환·중도상환 시뮬레이션 |
| 자산·대출·분양 일정·설정(편집) | 등록/수정/삭제, 세율 프리셋, 비밀번호 변경, 자동 잠금, 암호화 백업/복구 |

- 보기 모드 / 편집 모드: 등록·수정 화면은 편집 모드에서만 열립니다(전환 시 한 번 더 확인).
- 금액 가리기: 상단 눈 모양 버튼. 숫자가 ••••로 바뀌고, 가려진 숫자를 클릭하면 다시 보입니다.
- 화면 테마(밝게/어둡게/시스템)와 큰 글씨: 왼쪽 메뉴 아래.
- 홈 화면 추가(PWA): 휴대폰 브라우저 메뉴의 "홈 화면에 추가". 오프라인에서도 앱 화면이 열립니다.

## 설치와 실행 (Windows PowerShell)

Node.js 22 이상이 필요합니다.

```powershell
cd "$env:USERPROFILE\Desktop\Program\asset-tracker"
npm install        # 처음 한 번
Copy-Item .env.example .env.local   # Firebase 설정값 입력(docs/FIREBASE_SETUP.md 8번)
npm test           # 단위 테스트(계산 엔진, 암호화, 저장)
npm run dev        # 개발 서버: http://localhost:5173/asset-tracker/
npm run build      # 배포용 빌드(dist)
npm run preview    # 빌드 결과 확인
```

## 배포 (GitHub Pages)

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트 → 빌드 → 배포합니다. 테스트가 실패하면 배포되지 않습니다. 자세한 절차는 [docs/DEPLOY.md](docs/DEPLOY.md)를 보세요.

## 백업과 복구

데이터는 Firestore에 자동 저장되지만, Firebase 계정 문제·실수로 인한 삭제에 대비해 암호화 백업도 내려받아 두세요(마지막 백업 후 30일이 지나거나 데이터를 바꾼 뒤 백업하지 않았으면 대시보드에 알림이 뜹니다).

1. **백업**: 편집 모드 → 설정 → 백업 → "암호화 백업 내려받기". `asset-tracker-backup-날짜-시각.enc.json` 파일이 내려받아집니다. 파일 내용은 암호문이라 비밀번호 없이는 열 수 없습니다.
2. **보관**: 백업 파일은 프로젝트 폴더가 아닌 곳(다운로드 폴더, USB, 개인 클라우드 등)에 보관하세요. 저장소에는 `.gitignore`로 올라가지 않게 막혀 있습니다.
3. **복구**: 처음 화면의 "백업에서 복구" 또는 설정 → 백업 → "백업에서 복구"에서 파일과 **그 백업을 만들 때의 비밀번호**를 입력합니다. 복구하면 현재 데이터가 백업 내용으로 바뀌고, 이후 비밀번호도 백업의 비밀번호가 됩니다.

## 보안

- 2단계 잠금: ① Firebase 로그인(관리자 1명) ② 잠금 해제 비밀번호로 데이터 복호화.
- 잠금 해제 비밀번호 → PBKDF2(SHA-256, 600,000회, 랜덤 salt)로 키 유도 → AES-GCM 256으로 앱 전체 데이터를 통째로 암호화. 저장할 때마다 새 IV. 비밀번호와 키는 메모리에만 있습니다.
- Firestore 보안 규칙: 관리자 UID 한 개만 자기 문서 하나를 읽고 쓰기. 문서 구조·크기 검사, 저장할 때마다 버전 번호가 1씩 올라가야 함(오래된 화면의 덮어쓰기 방지). 그 밖의 모든 접근 거부.
- 가입 기능 끔 + 앱에 회원가입 화면 없음. API 키는 이 사이트 도메인과 필요한 API 3개로만 제한.
- 무조작 시 자동 잠금(기본 10분) = 로그아웃 + 메모리의 키와 데이터 삭제. 로그인 상태는 탭을 닫으면 사라집니다.
- 배포본 CSP: 외부 연결은 Firebase 주소 3개만 허용. 분석 도구·외부 CDN 없음.
- 점검 결과: [docs/SECURITY.md](docs/SECURITY.md)

## 한계

- **인터넷이 필요합니다**: 브라우저에 사본을 두지 않으므로 오프라인에서는 데이터를 볼 수 없습니다.
- **잠금 해제 비밀번호를 잊으면 복구할 수 없습니다.** 어디에도 저장되지 않기 때문입니다(로그인 비밀번호는 Firebase 콘솔에서 재설정 가능).
- 두 기기에서 동시에 수정하면 나중에 저장하는 쪽이 "다른 기기에서 먼저 저장됨" 안내를 받고 새로고침해야 합니다(덮어쓰기 방지).
- **모든 금액은 추정치**입니다. 이자는 단리·1년 365일 일할로, 대출 스케줄은 월 이율(연이율÷12)로 계산하며 실제 은행 계산(원 단위 절사, 실제 일수 등)과 다를 수 있습니다.
- 세율은 설정의 "세율 프리셋"을 따릅니다. 세금우대·2금융권 세금우대 초기값은 **예시값(확인 필요)** 이므로 가입 상품 안내문 기준으로 고쳐 쓰세요.
- 청약저축 이자는 기준일 이후분만 계산합니다(가입~기준일 사이 이자는 알 수 없어 제외).
- 분양 예측에서 주식·펀드는 현재 평가금액 그대로라고 가정합니다. 청약·분양 제도 조건은 앱이 판단하지 않고 자산별 "분양 시점 활용 가능" 입력을 따릅니다.
- 월이자지급식 예금도 받은 이자를 예금 평가액에 포함해 계산합니다(받은 이자를 현금 항목에도 입력하면 두 번 계산될 수 있음).

## 폴더 구조

```
src/
  crypto/      비밀번호 기반 암호화(PBKDF2 + AES-GCM)
  firebase/    Firebase 초기화, 로그인 상태, Firestore 문서 저장
  storage/     StorageAdapter 인터페이스, 버전 확인 저장(덮어쓰기 방지), 이전 버전용 IndexedDB, 백업 파일 형식
  data/        데이터 모델·검증·스키마(버전/마이그레이션)
  engine/      계산 엔진(순수 함수): 이자·세금, 대출, 순자산, Tip, 분양 예측, 알림
  session/     잠금 해제 세션, 자동 잠금, 실시간 시계, 화면 설정, 편집 모드
  pages/       화면
  components/  공통 컴포넌트(레이아웃, 금액 표시, 차트 설정 등)
  theme/       DashboardKit 템플릿 SCSS(MIT) + 앱 전용 스타일
public/        PWA manifest, 서비스 워커, 아이콘
firebase/      Firestore 보안 규칙 템플릿(관리자 UID는 배포 시 .env.local에서 넣음)
scripts/       아이콘 생성 스크립트
```
